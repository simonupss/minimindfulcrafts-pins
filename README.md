# minimindfulcrafts-pins

Pinterest pin images for the [Minimindfulcrafts](https://www.etsy.com/shop/minimindfulcrafts) Etsy shop: Japanese-inspired pastel nursery wall art.

The images in `pins/` are linked from the Pinterest bulk-upload CSV through their raw URLs:

`https://raw.githubusercontent.com/simonupss/minimindfulcrafts-pins/main/pins/<file>.jpg`

Please keep the file names unchanged, or the pins will stop loading.
